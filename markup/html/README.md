### GTM (Google Tag Manager) について

- Googleのサービスの一部でアクセス数の集計やコンバージョンの計測などを行うことができるサービス
- サイトにコードを記載することなく、Google Tag Managerの画面から設定を行うことができる

### アドブロック対策について

- 広告をブロックするアプリ、アドブロックを入れた状態で表示崩れが起きないかどうか


### 低電力モードでの表示崩れ対策について

- 動画ファイルをiPhoneと一部のAndroid端末では低電力モードで再生できない


### OGPタグ

- サイトのURLをSNS上でシェアした場合にURLと一緒に表示される画像です、シェア時の効果が高いため必須で設置するルールとなってます。

> 参考記事：https://kaikoku.blam.co.jp/client/digimaguild/knowledge/sns-pr/498

### iOSでアニメーションがちらつくとき

### サイトマップ

- ホームページの構造ツリー図にしたもの
- サイトマップを作成することで、サイトの構造を把握しやすくなる
  - カテゴリ、コンテンツをおおまかに分類する


### ディレクトリマップ
